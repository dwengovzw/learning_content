# Opdrachten opstellen toestandsdiagram

Hier worden een aantal oefeningen gegeven op het opstellen van toestandsdiagrammen op basis van de beschrijving van automaten. De opgave is telkens dezelfde:<br>

*Teken het toestandsdiagram van het opgegeven systeem. Benoem en nummer hierbij de toestanden, alsook de overgangspijlen*

## Opdracht 1: verkeerslicht 🚦
Aan een oversteekplaats voor voetgangers staat een verkeerslicht voor auto's. Dit licht wordt oranje wanneer een voetganger op een knop drukt. Na vier seconden krijgt het licht een signaal van een timer en springt op rood. Na 20 seconden krijgt het licht opnieuw een signaal van de timer en springt het op groen.

## Opdracht 2: parkeermeter 🅿️
Stel het toestandsdiagram op voor een eenvoudige parkeermeter. De prijs om te parkeren is altijd €2 en de meter geeft geen wisselgeld. Wanneer de gebruiker voldoende geld heeft ingeworpen, krijgt hij/zij een ticket. De meter heeft een sensor die kan voelen wanneer de gebruiker het ticket heeft weggenomen. Op die manier weet de automaat dat de volgende munt voor de volgende betaling is.

## Opdracht 3: slotmachine 🎰
In het casino staat een slot-machine met vier wielen. Wanneer een speler een munt in de machine steekt en aan de arm van de machine trekt, beginnen de wielen te draaien. De machine heeft een knop. Elke keer dat een speler op deze knop drukt, stopt er een wiel met draaien. Wanneer alle wielen stil staan kan de speler op een “betaal”-knop drukken. De machine geeft dan de winst in munten aan de speler (dit kan ook 0 munten zijn, een verlies dus). De speler kan dan opnieuw een munt in de machine steken.
